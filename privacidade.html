TRANSPARÊNCIA DE DADOS

Privacidade

Esta página explica, em linguagem direta, quais dados os formulários da Montana Tech Lab solicitam e para que eles são utilizados.

Dados solicitados

Podemos solicitar nome, empresa ou projeto, WhatsApp ou e-mail, site, objetivo, prazo e uma descrição do contexto. O diagnóstico também registra as alternativas escolhidas por você. Parâmetros de origem de campanha podem ser associados ao envio para entendermos qual canal trouxe o contato.

Finalidade

Os dados são usados para avaliar a aderência do projeto, preparar a conversa comercial e responder pelo canal informado. Eles não devem ser vendidos nem utilizados para finalidades incompatíveis com esse contato.

Tratamento e fornecedores

Quando a captação estiver configurada, os dados poderão passar por serviços de hospedagem, automação e organização comercial necessários ao recebimento do lead. O acesso deve ser limitado às pessoas e ferramentas envolvidas nesse processo.

Prazo e solicitações

Os dados devem ser mantidos apenas pelo período necessário para a conversa e para obrigações aplicáveis. Para pedir atualização ou exclusão, fale com o perfil oficial @montanatechlab.

Segurança do envio

O formulário só confirma o recebimento quando o destino configurado responde com sucesso. Se o canal automático estiver indisponível, a página informa isso e oferece um resumo para você continuar a conversa pelo Direct.

Última atualização: 21 de agosto de 2026.
